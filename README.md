# 📘 一、简介

该项目设计并制作了能够满足多种解锁任务的智能门锁，包括指纹、密码、IC 卡、蓝牙四种开锁方式，系统支持完善的本地管理员权限管理，包括用户信息的录入与删除（如密码修改、指纹 ID 和 IC 卡号管理），并配备 OLED 可视化人机交互界面以及状态提示、操作音效反馈。

**文件总览：**

CODE_HAL/
├── Core/
│   └── Src/
│       └── main.c                 // 主控流程：初始化外设，调度刷卡/指纹/蓝牙/菜单/开关锁
├── System/
│   ├── Delay.c                    // 微秒/毫秒级延时基准
│   ├── Flash.c                    // 底层 Flash 读写封装
│   ├── PasswordFlash.c            // 密码在 Flash 中的保存、读取、默认值处理
│   └── FingerprintFlash.c         // 指纹相关数据在 Flash 中的保存/管理
└── Hardware/
├── OLED.c                     // OLED 显示驱动
├── OLED_Data.c                // OLED 字模/图片数据表
├── Key.c                      // 4x4 矩阵键盘扫描与消抖
├── Motor.c                    // 门锁电机控制（开锁/关锁动作）
├── Menu.c                     // 菜单与业务页面逻辑
├── MFRC522.c                  // RFID 刷卡驱动与卡片识别
├── HC06.c                     // HC-06 蓝牙串口通信
├── BUZZER.c                   // 蜂鸣器提示音/报警音控制
└── AS608.c                    // AS608 指纹模块通信、录入、识别、删除能门锁

**各文件职责：**

- `main.c`：总调度
- `Menu.c`：业务状态机 / UI 流程
- `Key.c`、`BUZZER.c`、`Motor.c`、`OLED.c`、`OLED_Data.c`：本地交互与执行
- `MFRC522.c`、`AS608.c`、`HC06.c`：外部认证输入
- `Flash.c`、`PasswordFlash.c`、`FingerprintFlash.c`：持久化存储

# 📂 二、文件说明

<a id="main-c"></a>
## ⚙️ 1. main.c

1. 完成系统初始化、主循环状态切换、蓝牙密码解锁、RFID 刷卡解锁、指纹解锁、菜单功能跳转，以及定时器和串口中断回调处理
2. 轮询 + 标志位状态机：主循环不断地轮询，靠标志位判断应该进入的分支
3. 密码、蓝牙、刷卡、指纹四种入口在锁定状态下并行存在，谁先成功就谁触发开锁

<a id="delay-c"></a>
## ⏱️ 2. Delay.c

实现高精度忙等待延时，基于 CPU 周期计数器的精确延时

<a id="flash-c"></a>
## 💾 3. Flash.c

1. 通用底层 Flash 读写封装 
2. 提供三个函数：
- `FLASH_W()`：把 4 个字节写到指定 Flash 地址
- `FLASH_R()`：从指定地址读半字
- `FLASH_Clear()`：擦除指定地址所在页

<a id="passwordflash-c"></a>
## 🔐 4. PasswordFlash.c

1. 密码持久化管理模块，门锁密码掉电不丢失
2. 设置有效标识，检查密码是否有效：`PasswordFlash_Init()` 上电先读 `PASSWORD_FLASH_ADDR` 的内容，如果不是 `PASSWORD_VALID_MARK`，就说明 Flash 中没有有效密码，于是自动写入默认密码 `1106`。读密码时 `PasswordFlash_Read()` 也先检查 `valid_mark`，如果不对就返回失败。
3. 整页擦除后重写

<a id="fingerprintflash-c"></a>
## 👆 5. FingerprintFlash.c

1. 这里只设置了4个指纹存储位，即最多只能保存4个指纹的数据
2. 指纹槽位管理的 Flash 记录层。要注意，它不是存指纹模板本身；指纹模板真实存储在 AS608 指纹模块内部。这个文件只是在 MCU 的 Flash 里记录“哪些逻辑槽位已被占用”
3. 指纹模块内部有page0~127，即128个指纹模版，在业务层设置4个槽位，对应page0-3，方便管理和操作

<a id="oled-c"></a>
## 🖥️ 5. OLED.c

1. OLED 显示驱动 + 图形库，UI交互的核心
2. 软件 I2C 位操作
3. `OLED_DisplayBuf[8][128]` 是整个屏幕的显存镜像，8 页 × 128 列，对应 128×64 OLED 的页寻址结构。所有绘图操作都先改这个缓冲区，而不是立即写屏；真正更新屏幕时才调用 `OLED_Update()` 或 `OLED_UpdateArea()`

<a id="oled-data-c"></a>
## 🧩 6. OLED_Data.c

1. OLED 显示资源库，也就是 `OLED.c` 的数据后端
2. 资源内容：
- ASCII 字模：`OLED_F8x16`、`OLED_F6x8`、`OLED_F12x24`
- 中文字模表：`OLED_CF16x16`
- 图片资源：`Boxleft`、`Boxright`、`Diode`、`Return`、`Eyebrow1`、`Eyebrow2`、`Mouth`、`Lock`、`Empty` 等

<a id="key-c"></a>
## ⌨️ 7. Key.c

1. 4×4 矩阵键盘扫描与消抖模块
2. 把 4 根行线和 4 根列线分配到不同的 GPIO 上，然后逐行输出低电平、逐列读输入，判断当前按下的是哪一个按键，最终映射成 1~16
3. 定时器消抖，在定时中断里固定频率扫描，再只在“松开瞬间”提交事件，这样用户按住某个键不放也不会疯狂连发

<a id="motor-c"></a>
## 🔁 8. Motor.c

1. 4 相步进电机开锁控制 
2. 按 step 0~7 依次设置四个相位引脚。8 拍半步驱动：单相、双相交替。半步模式比全步更平滑，也更容易控制细分角度
3. `Motor_DirectionAngle90()` 并没有精确算 90° 对应多少步，而是记录 `start_time = HAL_GetTick()`，持续运行 3000ms，并以 5rpm 调 `Motor_DirectionSpeed()`。运行时间 3 秒转半圈，这里实际上是时间控制法，不是绝对步数控制

<a id="menu-c"></a>
## 🧭 9. Menu.c

1. 业务逻辑与 UI 状态机：开机动画、锁定界面、解锁密码输入、菜单翻页、改密码、录入新卡、删除卡片、录入指纹、删除指纹
2. 页面式状态机：
- `Lock_Page()`：锁定页
- `UnLock_Page()`：密码解锁页
- `First_Page()`：一级菜单页
- `OldPassword_Page()` / `NewPassword_Page()`：改密码流程
- `Add_Card_Page()` / `Delete_Card_Page()`：卡片管理
- `Add_Fingerprint_Page()` / `Delete_Fingerprint_Page()`：指纹管理

<a id="mfrc522-c"></a>
## 📡 10. MFRC522.c

1. RFID 读卡器 RC522 的完整驱动层
2. 软 SPI 位操作，标准 ISO14443A / Mifare 协议链路：
- `PcdRequest()`：寻卡
- `PcdAnticoll()`：防冲突取 UID
- `PcdSelect()`：选卡
- `PcdAuthState()`：块认证
- `PcdRead()` / `PcdWrite()`：块读写

这里只用到了UID匹配功能

<a id="hc06-c"></a>
## 📶 11. HC06.c

1. 蓝牙串口通信辅助模块，本质上是一个围绕 `USART1` 的发送封装
2. 通过手机连接蓝牙发送4位密码进行开锁验证

<a id="buzzer-c"></a>
## 🔔 12. BUZZER.c

1. 蜂鸣器声反馈模块：GPIO 电平控制 + 不同时长的阻塞延时

<a id="as608-c"></a>
## 🧬 13. AS608.c

1.  AS608 指纹模块协议驱动 + 高层录入 / 识别封装：实现了指纹协议包的发送、接收、解析；另一方面又提供了“等待手指识别一次”“录入新指纹”“删除模    板”等业务级接口
2. 高层业务函数封装：
- `AS608_IdentifyOnce()`：等手指 → 取图 → 生成特征 → 搜索
- `AS608_Add()`：两次按压 → 两次取图 → 两次特征 → 合并 → 存储
- `AS608_Delete()`：删模板
- `AS608_ClearAll()`：清空库
1. 一次识别，单次按压识别流程：`AS608_IdentifyOnce()`
- 在总超时内等 `PS_ReadTouch()`
- 给图像采集 3 秒小超时，循环调用 `PS_GetImage()`
- 成功后执行 `PS_GenChar(1)` 生成特征
- 然后 `PS_Search(1, 0, 128, &res)` 在模板库中搜索
- 找到则把 `pageID` 返回给上层
1. 指纹录入，双采样录入流程：`AS608_Add()`
- 等第一次按压
- 取图成功后 `PS_GenChar(1)`
- 等手指移开
- 延时 200ms
- 等第二次按压
- 再次取图并 `PS_GenChar(2)`
- `PS_RegModel()` 合并两个特征
- `PS_StoreChar(1, pageID)` 存入模板库
