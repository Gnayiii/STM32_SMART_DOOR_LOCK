# 📘 一、简介

该项目设计并制作了能够满足多种解锁任务的智能门锁，包括指纹、密码、IC 卡、蓝牙四种开锁方式，并集成反暴力锁定、自动回锁、独立看门狗与开锁审计日志等安全机制，在保障解锁便捷的同时提升系统健壮性与安全防护；系统支持完善的本地管理员权限管理，包括用户信息的录入与删除（如密码修改、指纹 ID 和 IC 卡号管理），并配备 OLED 可视化人机交互界面以及状态提示、操作音效反馈。

**文件总览：**
```text
CODE_HAL/
├── Core/
│   └── Src/
│       └── main.c                 // 主控流程：初始化外设，调度刷卡/指纹/蓝牙/菜单/开关锁
├── System/
│   ├── Delay.c                    // 微秒/毫秒级延时基准
│   ├── Flash.c                    // 底层 Flash 读写封装
│   ├── PasswordFlash.c            // 密码异或加扰后在 Flash 中保存、读取、默认值处理
│   ├── FingerprintFlash.c         // 指纹相关数据在 Flash 中的保存/管理
│   ├── WDT.c                      // 独立看门狗（IWDG）初始化与喂狗
│   └── Security.c                 // 反暴力锁定 / 自动回锁 / 开锁审计日志
└── Hardware/
├── OLED.c                     // OLED 显示驱动
├── OLED_Data.c                // OLED 字模/图片数据表
├── Key.c                      // 4x4 矩阵键盘扫描与消抖
├── Motor.c                    // 门锁电机控制（开锁/关锁动作）
├── Menu.c                     // 菜单与业务页面逻辑
├── MFRC522.c                  // RFID 刷卡驱动与卡片识别
├── HC06.c                     // HC-06 蓝牙串口通信
├── BUZZER.c                   // 蜂鸣器提示音/报警音控制
└── AS608.c                    // AS608 指纹模块通信、录入、识别、删除模板
 ```
**各文件职责：**

- `main.c`：总调度
- `Menu.c`：业务状态机 / UI 流程
- `Key.c`、`BUZZER.c`、`Motor.c`、`OLED.c`、`OLED_Data.c`：本地交互与执行
- `MFRC522.c`、`AS608.c`、`HC06.c`：外部认证输入
- `Flash.c`、`PasswordFlash.c`、`FingerprintFlash.c`：持久化存储
- `WDT.c`、`Security.c`：系统健壮性与安全策略（看门狗 / 反暴力锁定 / 自动回锁 / 审计日志）

# 📂 二、文件说明

<a id="main-c"></a>
## ⚙️ 1. main.c

1. 完成系统初始化、主循环状态切换、蓝牙密码解锁、RFID 刷卡解锁、指纹解锁、菜单功能跳转，以及定时器和串口中断回调处理
2. 轮询 + 标志位状态机：主循环不断地轮询，靠标志位判断应该进入的分支
3. 密码、蓝牙、刷卡、指纹四种入口在锁定状态下并行存在，谁先成功就谁触发开锁
4. 安全机制集成：四通道统一经过安全门禁（反暴力锁定），主循环顶部按时喂狗，解锁态自动检查是否需要回锁

<a id="delay-c"></a>
## ⏱️ 2. Delay.c

实现高精度忙等待延时，基于 CPU 周期计数器的精确延时

<a id="flash-c"></a>
## 💾 3. Flash.c

1. 通用底层 Flash 读写封装 
2. 提供三个基础操作：整字写入（一次写 4 字节）、半字读取、整页擦除（按地址定位所在页）

<a id="passwordflash-c"></a>
## 🔐 4. PasswordFlash.c

1. 密码持久化管理模块，门锁密码掉电不丢失
2. 密码加扰存储：写入前将密码每字节与固定密钥异或，Flash 中不落明文；读取时先拷贝到内存再逐字节还原，避免直接改写 Flash 指针
3. 有效标识区分新旧格式：上电时先读标志区，若不是异或格式的有效标识，说明 Flash 中没有有效密码，自动写入异或后的默认密码 `1106`；读密码时也先校验有效标识，不对则返回失败
4. 整页擦除后重写

<a id="fingerprintflash-c"></a>
## 👆 5. FingerprintFlash.c

1. 这里只设置了4个指纹存储位，即最多只能保存4个指纹的数据
2. 指纹槽位管理的 Flash 记录层。要注意，它不是存指纹模板本身；指纹模板真实存储在 AS608 指纹模块内部。这个文件只是在 MCU 的 Flash 里记录“哪些逻辑槽位已被占用”
3. 指纹模块内部有page0~127，即128个指纹模版，在业务层设置4个槽位，对应page0-3，方便管理和操作

<a id="wdt-c"></a>
## ⏰ 6. WDT.c

1. 独立看门狗（IWDG）封装：初始化时配置预分频 256、重载 4095，由 HAL 自动启动 LSI；喂狗接口周期性刷新计数器
2. 最坏情况（LSI 60kHz）下看门狗周期约 17.5s，主循环、全部菜单页面循环以及 AS608 等待循环均按时喂狗，程序跑飞自动复位
3. 调试适配：调试模式下冻结看门狗计数，保证 SWD 断点调试时不会反复复位

<a id="security-c"></a>
## 🛡️ 7. Security.c

1. 安全策略模块，统一管理四通道（密码 / RFID / 指纹 / 蓝牙）的认证安全机制
2. 反暴力锁定：任一通道连续失败 5 次后锁定 30 秒，期间所有开锁入口被安全门禁拦截，锁定页仅显示倒计时
3. 自动回锁：认证成功后开始可配置的倒计时（当前默认 30 秒），到期自动执行关锁；解锁态下每次按键操作都会刷新倒计时（活动续期），主循环与各菜单页面循环统一检查
4. 开锁审计日志：每次认证结果（通道 + 成功/失败 + 序号）写入 Flash 专用页，整页重写、magic 最后写入作为提交点，掉电不损坏其它数据

<a id="oled-c"></a>
## 🖥️ 8. OLED.c

1. OLED 显示驱动 + 图形库，UI交互的核心
2. 软件 I2C 位操作
3. 内置整屏显存镜像（8 页 × 128 列，对应 128×64 OLED 的页寻址结构）。所有绘图操作都先修改显存，而不是立即写屏；真正更新屏幕时才一次性刷到屏上，支持整屏或按区域刷新

<a id="oled-data-c"></a>
## 🧩 9. OLED_Data.c

1. OLED 显示资源库，也就是 OLED 驱动的数据后端
2. 资源内容：ASCII 字模（8×16、6×8、12×24 三种字号）、中文字模表（16×16）、界面图片资源（左右边框、指示灯、返回箭头、眉毛、嘴、锁、空等）

<a id="key-c"></a>
## ⌨️ 10. Key.c

1. 4×4 矩阵键盘扫描与消抖模块
2. 把 4 根行线和 4 根列线分配到不同的 GPIO 上，然后逐行输出低电平、逐列读输入，判断当前按下的是哪一个按键，最终映射成 1~16
3. 定时器消抖，在定时中断里固定频率扫描，再只在“松开瞬间”提交事件，这样用户按住某个键不放也不会疯狂连发

<a id="motor-c"></a>
## 🔁 11. Motor.c

1. 4 相步进电机开锁控制 
2. 按 step 0~7 依次设置四个相位引脚。8 拍半步驱动：单相、双相交替。半步模式比全步更平滑，也更容易控制细分角度
3. 转动控制并未精确换算角度与步数，而是记录起始时间后持续驱动电机 3000ms（约 5rpm），运行 3 秒转半圈，属于时间控制法而非绝对步数控制

<a id="menu-c"></a>
## 🧭 12. Menu.c

1. 业务逻辑与 UI 状态机：开机动画、锁定界面、解锁密码输入、菜单翻页、改密码、录入新卡、删除卡片、录入指纹、删除指纹、查看开锁日志
2. 页面式状态机，每个页面独立处理自身循环：锁定页、密码解锁页、一级菜单页、改密码流程（验证旧密码 / 输入新密码）、卡片管理（录入 / 删除）、指纹管理（录入 / 删除）、开锁日志页（查看最近认证记录）

<a id="mfrc522-c"></a>
## 📡 13. MFRC522.c

1. RFID 读卡器 RC522 的完整驱动层
2. 软 SPI 位操作，标准 ISO14443A / Mifare 协议链路：寻卡、防冲突取 UID、选卡、块认证、块读写

这里只用到了UID匹配功能

<a id="hc06-c"></a>
## 📶 14. HC06.c

1. 蓝牙串口通信辅助模块，本质上是对蓝牙串口的发送封装
2. 通过手机连接蓝牙发送4位密码进行开锁验证

<a id="buzzer-c"></a>
## 🔔 15. BUZZER.c

1. 蜂鸣器声反馈模块：GPIO 电平控制 + 不同时长的阻塞延时

<a id="as608-c"></a>
## 🧬 16. AS608.c

1.  AS608 指纹模块协议驱动 + 高层录入 / 识别封装：实现了指纹协议包的发送、接收、解析；另一方面又提供了“等待手指识别一次”“录入新指纹”“删除模板”等业务级接口
2. 高层业务接口：
- 识别一次：等手指 → 取图 → 生成特征 → 库内搜索
- 录入新指纹：两次按压 → 两次取图 → 两次特征 → 合并 → 存储
- 删除模板
- 清空指纹库
3. 一次识别，单次按压识别流程：
- 在总超时内等手指按下
- 给图像采集 3 秒小超时，循环尝试取图
- 成功后生成特征
- 再在模板库中搜索匹配
- 找到则把指纹 ID 返回给上层
4. 指纹录入，双采样录入流程：
- 等第一次按压
- 取图成功后生成第一份特征
- 等手指移开
- 延时 200ms
- 等第二次按压
- 再次取图并生成第二份特征
- 合并两份特征
- 存入模板库对应槽位

<a id="hardware"></a>
# 🔧 四、硬件

原理图+PCB+BOM见文件夹：SCHEMATIC_PCB

**核心硬件：**

- 主控：STM32F103C8T6（Cortex-M3，72MHz，64KB Flash / 20KB RAM）
- 显示：0.96 寸 OLED（IIC 接口）
- 输入：4×4 矩阵键盘
- 认证模块：AS608 指纹模块、RC522 RFID 读卡器、HC-06 蓝牙模块
- 执行：四相步进电机（开锁/关锁动作）
- 反馈：蜂鸣器（按键/开锁/成功/错误提示音）

**开发环境：**

- Keil MDK-ARM（ARM Compiler V6）
- STM32CubeMX + STM32Cube HAL F1 库
- SWD 下载调试
